Impressive work on these Word/Excel/Powerpoint clones:

https://getartcraft.com/apps/wordcraft

https://getartcraft.com/apps/gridcraft

https://getartcraft.com/apps/deckcraft

It's almost ridiculous how small and fast these apps are. Let's see where this goes. From what I see, each project has about hundreds of active pull requests, so the development pace should be fast.

The same team creates lots of other clones, especially of Adobe suite apps.

https://getartcraft.com/apps

What's more, thanks to writing in Rust, the apps are Linux natives.
Snap versions are created here:

https://github.com/kenvandine?tab=repositories

https://snapcraft.io/gridcraft

https://snapcraft.io/wordcraft

https://snapcraft.io/deskcraft

Observation on October 2026, version 0.10: old binary xls files aren't well supported yet.
Overall feeling: this can be a mature project by this Christmas.
