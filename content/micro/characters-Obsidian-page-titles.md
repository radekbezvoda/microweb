If you are multiplatforming like me, the inconsistencies between supported file name characters can bite you.

I created a file with a heading containing question mark on Linux. This replicates well in Obsidian among Linux clients, but doesn't if I use Windows.

This is a clear limitation of file-based Obsidian approach.
